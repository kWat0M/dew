# 0033: URL と一緒に DEW_PUBLIC_HOST / DEW_PUBLIC_PORT の設定を出す

- 日付: 2026-11-03
- 状態: 採用

`dew`・`dew url`・`dew status`(と、`dew run` などで初めてサーバを起動したとき)は、URL の後に、URL を作るのに使った `DEW_PUBLIC_HOST` / `DEW_PUBLIC_PORT` と待ち受けポートを出す。ゼミで共用の Linux サーバに直接入れて使うと、未設定のまま localhost の URL になる、`~/.bashrc` に書いても動いているサーバには効かない、ほかの人が先に使っていて待ち受けポートが黙ってずれる、といったことで開けないことが多く、その原因を端末の表示だけで探せるようにするため(利用者の要望)。サーバは起動したときの環境変数を使い続けるので、起動時の値(書かれたままの文字列。未設定・空は null)を `server.json` の `public` に残し、表示する CLI の端末の値と違えば、`dew stop` してから起動し直すよう注意を出す。数として読めない `DEW_PUBLIC_PORT` や、ポートがずれて使わなかった `DEW_PUBLIC_PORT` は「使っていない」と出す。表示は標準エラー出力にして、標準出力は今までどおり URL だけにした(`$(dew url)` のように使えるように)。記録のない前の版のサーバでは何も出さない。
