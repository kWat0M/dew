# 0026: ドキュメントウィンドウの操作の見直し その2(Esc で抜けない、マウス、バーのボタン)

- 日付: 2026-10-22
- フェーズ: 6
- 状態: 採用

0025 のあとのユーザーの確認を受けて、次のように変えた(spec 15.3・17.4 にも書いた)。(1) 文書の入力モードとリンクヒントは `Esc` では抜けない。ライブウィンドウの入力モード(`Ctrl+]` で抜ける)と抜け方をそろえるため。入力モードは `q` か `Ctrl+]` で抜け、ヒントは `Backspace` で閉じる。ヒントを出している間の `Ctrl+]` は、ヒントだけでなく入力モードごと抜ける(どこでも「`Ctrl+]` = 入力モードを抜ける」にそろえる)。目次も `Esc` では閉じず、`o` か `Backspace` で閉じる。検索欄で文字を打っている間だけは、文字入力欄の普通の動きとして `Esc` で検索欄を閉じる。また `Ctrl+]` は検索欄からでも効くようにした。(2) ヒントを出している間は、画面下のヒントの帯を、ヒントの選び方と抜け方(`Backspace` / `Ctrl+]`)に切り替える。入力モードの帯には `F`(新しいウィンドウで開く)も足した。
