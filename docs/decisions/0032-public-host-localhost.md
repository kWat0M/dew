# 0032: DEW_PUBLIC_HOST が未設定なら URL を localhost で作る

- 日付: 2026-10-25
- 状態: 採用

`DEW_PUBLIC_HOST` が未設定のとき、端末に出す URL のホスト名を、マシンのホスト名から `localhost` に変え、メッセージも警告から注意(「URL には localhost を使います」)にした。利用者は WSL で dew を使うことが多く、WSL2 では Windows のブラウザから `localhost` でそのまま開けるのに、環境変数を足さないとマシンのホスト名の URL(Windows から引けないことがある)が出ていたため。WSL かどうか・コンテナの中かどうかは判定しない。利用者の指定で、判定を増やさず「設定されていれば使い、なければ localhost」という分かりやすい決まりにした。リモートのサーバやコンテナでポートを公開する場合は、今までどおり `DEW_PUBLIC_HOST` を設定してもらう(README の手順のとおり)。注意の文に設定の仕方を添えて、気づけるようにした。自己署名証明書の対象名には、もともと localhost も含めている。
