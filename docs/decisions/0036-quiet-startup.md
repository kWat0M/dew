# 0036: 起動時の表示を減らす

- 日付: 2026-11-11
- 状態: 採用

`dew` を起動したときの表示が多く(ツールが何もないサーバで12行)、URL が途中に埋もれて見づらいことと、要らない機能のツールは入れずに使い続けることもあるのに、起動のたびに使えない機能が並ぶのはよくないこと(利用者の要望)から、表示を「毎回出すのは URL と、対処が要るものだけ」「変わらない状況は一度だけ」「詳しくは聞かれたときに」の3つに分けた。足りないツールは、機能ごとに並べていた注意と入れ方の行をやめ、「ツール不足により、一部機能に制限があります(詳細はdew doctor)」の1行にした(文言は利用者の指定)。この行は、足りないツールのパッケージ名を `~/.local/share/dew/notified-missing-tools` に残し、前に知らせたときと変わったとき(初めて、ツールが増えた・減った)だけ出す。その機能を使おうとした場所では、今までどおり毎回、理由と入れ方を出す(ADR 0019)ので、起動時に毎回言わなくても困らない。消す設定や `--quiet` は作らない(毎回付けるのは手間で、ポートがずれたなどの対処が要る注意まで見落とすため)。URL の設定(ADR 0033、0035)は、ホストとポートを「URL の host: 192.168.1.10(dew config host)・port: 8765(default)」の1行にした(host・port の表記は利用者の指定)。かっこの中の出どころは、環境変数(`DEW_PUBLIC_HOST` / `DEW_PUBLIC_PORT`)、設定ファイル(`dew config host` / `dew config port`)、未設定(`default`。localhost と待ち受けポート)のどれかで、空の環境変数は「DEW_PUBLIC_HOST が空」、待ち受けポートがずれて設定を使えなかったときは「待ち受けポート。… の N は使っていない」と出す。サーバが出していた「URL には localhost を使います」は、この行と同じことなのでやめた。URL は見つけやすいよう最後に出す。閲覧範囲は、その下が見られることが分かるよう末尾に `/` を付け(利用者の指定)、変え方(`dew stop` の後 `--root`)は `dew status` でだけ添える。端末の値がサーバを起動したときと違うときの注意と、ポートがずれたときの警告は、対処が要るので今までどおり出す。
