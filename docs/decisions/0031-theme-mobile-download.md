# 0031: テーマの切り替え・スマホの画面・ダウンロード

- 日付: 2026-10-24
- 状態: 採用

利用者の要望で、テーマをライト・ダークに固定できるようにし、スマホの幅でも Home と文書を使えるようにし、ファイルを保存できるようにした(spec 18 章)。テーマはブラウザごとに保存する。端末ごとに明るさの好みが違うことが多く、サーバに1つだけ持つと PC とスマホで同じになってしまうため。色はもともと `web/src/theme/` のトークンだけで決めているので、トークンの定義を `data-theme` にも対応させるだけで全体が切り替わる。読み込んだ瞬間にブラウザの色で一度描いてから変わるのを避けるため、`index.html` で最初の描画の前に属性を付ける。スマホは、利用者が ssh で入ったサーバからトークン付きの URL を開けるので、接続や認証の仕組みは変えず、画面の幅だけで表示を変える(端末の種類では判定しない。PC でウィンドウを狭くしたときも同じ表示になる)。境目は MD3 の Compact window size class の 600px。狭い画面では複数のウィンドウを並べても読めないので、キャンバスは1つずつ全画面にし、Home もプレビューを省いて1カラムにする。キーボードがない前提なので、キーの案内と、ライブの入力モードは出さない。ダウンロードは、1つのファイルはそのまま、複数とディレクトリは zip にまとめる。zip は新しい外部依存(`zip` クレート)だが、利用者の承認を得た。まとめながら送り、一時ファイルを作らない(大きなディレクトリでも待たずに保存が始まり、ディスクも使わない)。動画・画像はすでに圧縮されていて Deflate しても小さくならず時間だけかかるので、テキストだけを圧縮する。閲覧範囲の外を指すシンボリックリンクは、範囲で持ち出せるものを限る趣旨(7.2)に合わせて入れない。キーは、どのキーマップでも使っていない `D` を充てた(操作モードでも、ウィンドウが使わないキーとしてキャンバスの操作になる)。
