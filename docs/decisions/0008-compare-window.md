# 0008: 比較ウィンドウの作り

- 日付: 2026-10-16
- フェーズ: 2
- 状態: 採用

比較(F7)は、仕様では「比較ビュー」とだけあり画面の作りが決まっていなかった。キャンバスの「全部フローティングウィンドウ」の考え方にそろえ、選んだファイルを1つのウィンドウに入れる「比較ウィンドウ」にした(別の画面にすると、操作体系を1つにそろえる方針に反するため)。表示は 並べる / スライダー / 差分 の3つで、切り替えても動画を読み込み直さないよう、要素は同じまま配置と CSS だけを変える。差分は2つ目を `mix-blend-mode: difference` で重ねて GPU に合成させる(WebGL や canvas で画素ごとに計算する案は、動画の毎フレームの処理が重く、実装も増えるため選ばなかった)。中の動画は常に1つ目を基準に同期させ、キャンバスの `s` と同じ仕組み(`SyncGroup`)を使う。スライダーと差分は2つまでを比べるので、3つ以上のときは1つ目と2つ目を使う。
