# 0020: ソースを公開し、配布物を同じリポジトリに置く

- 日付: 2026-10-19
- フェーズ: 配布
- 状態: 採用(ADR 0018 の配布先を置き換える)

v0.1.0 は、ソースのリポジトリ(kWat0M/DevView)を非公開のまま、バイナリだけを置く公開リポジトリ kWat0M/dew-releases の Releases で配った。使ってもらった友人から、開発とリリースのリポジトリが分かれていることに違和感がある、という意見があり、ユーザーも同じ考えになったので、ソースのリポジトリを `kWat0M/dew` に改名して公開し、配布物もその Releases に置き、dew-releases は消すことにした(ユーザーの決定)。非公開にしていた理由の、公開できないテスト素材(tests/fixtures/ の一部)は一度もコミットしておらず、履歴にも残っていないことを確かめた。コミットの作者のメールアドレスは GitHub の noreply のもの。`dew update` の既定の取得先(`DEFAULT_REPO`)を `kWat0M/dew` にし、LICENSE・README の配布場所も変えた。0.1.0 の dew は dew-releases を見るため、消したあとの `dew update` は取得できずに手で入れ替える方法を出す。0.1.0 を入れた人には一度だけ入れ直してもらう(CHANGELOG に書いた)。LICENSE の利用条件(再配布の禁止、GitHub 上での閲覧とフォークは除く)は変えない。
