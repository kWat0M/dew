# 0006: 再生ボタン群の並びと、タイル配置での拡大・縮小

- 日付: 2026-10-16
- フェーズ: 1
- 状態: 採用

再生ボタン群は、依頼の並び「[5秒戻り][30秒戻り][再生停止][30秒送り][30秒戻り]」の最後を「5秒送り」の書き間違いと解釈し、左右が鏡写しになる `[コマ戻り][5秒戻り][30秒戻り][再生 / 停止][30秒送り][5秒送り][コマ送り]` にした。5秒・30秒のアイコンは、自作の形では数字と矢印がずれたため、Material Symbols の replay_5 などを使う(ADR 0007)。操作パネルの「拡大・縮小」は自由配置でしか意味を持たない。タイル配置で押されたら自動で自由配置に切り替える案も試したが、配置が勝手に変わるのは分かりにくいため、配置は変えずに「自由配置でできる操作です」と Snackbar で伝える。
