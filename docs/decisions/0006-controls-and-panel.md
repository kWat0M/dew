# 0006: 再生ボタン群の並びと、タイル配置での拡大・縮小

- 日付: 2026-10-16
- フェーズ: 1
- 状態: 採用

再生ボタン群は、依頼の並び「[5秒戻り][30秒戻り][再生停止][30秒送り][30秒戻り]」の最後を「5秒送り」の書き間違いと解釈し、左右が鏡写しになる `[コマ戻り][5秒戻り][30秒戻り][再生 / 停止][30秒送り][5秒送り][コマ送り]` にした。5秒・30秒のアイコンは数字入りの既製アイコンを持たないため、円い矢印に秒数を重ねて描き、送りは矢印を左右反転する。操作パネルの「拡大・縮小」は自由配置でしか意味を持たないが、マウスだけの人がタイル配置で押しても何も起きないのは分かりにくいため、タイル配置で押されたら今のタイルの位置のまま自由配置に切り替えてから大きさを変える。
