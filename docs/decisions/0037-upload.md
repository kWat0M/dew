# 0037: Home のアップロード

- 日付: 2026-11-13
- 状態: 採用

利用者の要望で、ローカルの端末から Home の今のディレクトリ(2カラム目)へファイルを送れるようにした(spec 19 章)。操作は、上部のバーのボタンか `U` でブラウザのファイルの選択画面を開く方法と、Home の画面へのドラッグ&ドロップの2つ。dew はこれまで「読み取り専用」だったが、足すのは新しいファイルを作ることだけにし、既存のファイルの上書き・削除・移動は今後も持たない(取り返しのつかない操作をブラウザから行えないようにするため)。そのため、同じ名前があるときは上書きせず「名前 (1).拡張子」にする(OS のダウンロードと同じ付け方)。同時に同じ名前が作られても上書きしないよう、書きかけの隠しファイルからハードリンクで名前を付ける。送り方は、1ファイルずつ本文をそのまま送る `PUT` にした。multipart にしないのは、サーバでの解析が要らず、少しずつ書けて大きなファイルでもメモリを使わず、ブラウザの XHR で進み具合をそのまま出せるため。大きさの上限は設けない(保存と同じく、使う人が自分の環境で使うもので、ディスクの空きが足りなければ書き込みの失敗として知らせる)。ディレクトリのドラッグ&ドロップは対象外にした(ディレクトリを作る操作が要り、ブラウザごとの差も大きい。必要になったら足す)。送り先をカーソルの位置ではなく今のディレクトリにしたのは、要望が「2カラム目のディレクトリに追加」であることと、カーソルがファイルのときに迷わないようにするため。設定での無効化は設けていない(ほかの API と同じくトークンがなければ使えず、書けるのは閲覧範囲の中に新しいファイルを足すことだけなので)。
