# 0005: フェーズ1のキャンバスで作らないキーと、フレーム番号の追い方

- 日付: 2026-10-15
- フェーズ: 1
- 状態: 採用

5.3 のキーのうち、`s`(同期再生)はフェーズ2(F7)、`i`(入力モード)と `w r` はフェーズ3、`r`(録画)はフェーズ4の機能なので、フェーズ1では割り当てない。`:`(コマンドパレット)はフェーズ1の受け入れ基準になく、すべての操作がキーで行えるため後回しにし、`?` のキー一覧だけ作る。エラー表示(7.11)の「ログを見る」は、サーバのログを見る API がまだないため、ウィンドウ内に ffmpeg のエラー要約だけを出す。表示中のフレーム番号は requestVideoFrameCallback の mediaTime から求めるが、コマ送りの起点には「最後に表示されたフレーム」と「自分でシークした行き先」のうち新しいほうを使う。Chrome ではシーク直後にこの通知が遅れ、一時停止直後の currentTime が表示中のフレームより1〜2フレーム手前になることがあり、どちらか片方だけでは1フレームずれたため。シーク先はフレームの時刻ちょうどではなく、表示期間の 1/4 だけ後ろにする(境界で前のフレームが出ないように)。
