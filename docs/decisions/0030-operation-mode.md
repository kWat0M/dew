# 0030: キャンバスの操作モードと、抜けるキー(Esc・Ctrl+[・q)

- 日付: 2026-10-24
- 状態: 採用

利用者の要望で、キャンバスのキー操作を vim のノーマル / インサートに近づけた。ノーマルモードの hjkl はウィンドウの選択(以前の `w` hjkl)にし、`i` / Enter / ウィンドウの本体のクリックで、そのウィンドウの中を操作する「操作モード」に入る。動画の再生も操作モードで行う。以前は Markdown・CSV の操作も「入力モード」と呼んでいたが、アプリへ入力を送るライブウィンドウのものだけを入力モードと呼び、ライブは操作モードからさらに `i` で入る2段にした。`h` で Home へ戻るキーは Tab と同じなので外した。モードや入力欄を抜けるキーは Esc・`Ctrl+[`・`q` にそろえ、文字を打つ欄では `q`、ライブの入力モードでは Esc と `q`(アプリへ送る)を外す。入力モードを抜けるキーは、もともと Esc をアプリへ送るための代わりとして vim で Esc の代わりに使う `Ctrl+[` を充てるつもりだったので、`Ctrl+]` から改めた。`Ctrl+[` は `key` で判定し、物理キーの位置(`code`)では判定しない(以前は `code` の BracketRight も見ていたため、日本語配列の `Ctrl+[` が `Ctrl+]` と見なされ、ライブの入力モードを抜けていた)。開いているもの(ヒント・目次・検索欄・小さな画面)は抜けるキー1回で1段ずつ閉じ、文字の欄は Esc・`Ctrl+[` で欄から抜けるだけにして欄を残す。ライブの巻き戻しからライブへ戻るキーは、`q` が抜けるキーになったので `G`(vim の末尾へ)にした。操作モードのウィンドウが使わないキー(`w`・`r`・`f`・`?` など)は、ノーマルモードと同じキャンバス全体の操作として効かせる(動画を見ながら `f` で最大化するたびに抜けなくて済むように)。キーはキャンバスがまとめて受け取り、操作モードのウィンドウに配る(`web/src/canvas/op.ts`)。選択中のウィンドウから操作モードに入ると、選択中の同じ種類のウィンドウもまとめて入り、同じキーが全部に効く(ファイルの見比べのため。種類を混ぜると、同じ `j` がスクロールと 5 秒戻るになって分かりにくいので混ぜない)。小さな画面・検索欄・目次・コピー・ブラウザの履歴の操作は先頭(フォーカス中)のウィンドウだけで行い、決めた内容をほかのウィンドウにも渡して、それぞれの選択中の列・位置に適用する。CSV では、列の型で使えない条件(文字列の列に `>` など)は適用せずに件数を知らせ、表にない列を指す表示設定は読み込むときにも除く(`cleanView`)。ない列を参照して画面が崩れたり、保存された設定で開くたびに失敗したりしないようにするため。Markdown のリンクヒントは、キャンバスが全ウィンドウの見えているリンクを数えてから文字を割り当て、重ならないようにする。複数のライブウィンドウへの入力は、X のキーの行き先が1つしかないので、ウィンドウごとに「行き先の切り替え・押す・離す」を1回の操作(`LiveInput::Tap`)で送る。ウィンドウごとの WebSocket から押す・離すを別々に送ると、切り替えが混ざって別のウィンドウに届いたため(E2E が負荷の高いときに落ちた)。押しっぱなしは送れない。マウスは、本体のクリックで操作モード、タイトルバーはフォーカスだけ(移動のドラッグやボタンのたびに切り替わらないように)、ウィンドウの外(上部のバー・タブバー・何もない所・ヒントの帯)で抜ける。操作パネルは操作モードの中で使うものなので、押しても抜けない。複数で操作モードのときにその中のウィンドウを押しても、まとまりは崩さず先頭にする(先頭のウィンドウの小さな画面を押すたびに崩れないように)。ライブウィンドウのクリックは操作モードに入るだけで、アプリへは送らない。枠の色はフォーカス・操作モード・入力モードを見分けやすいよう、利用者の好みの明るい tokyonight の色(ライトでは tokyonight day)にした。MD3 の色からは選べないので、dew 独自の色のトークンとして `web/src/theme/frame.css` に置き、ほかの部品と同じくトークン経由で使う。CSV の小さな画面の選択欄は、ブラウザ標準の select が hjkl で選べないので、MD3 の Exposed dropdown menu として自前で作った(`web/src/ui/MenuSelect.tsx`)。欄の移動は、欄の見た目の位置(上下は一番近い行で横の位置が近いもの)で決め、画面ごとに並びを書かずに済むようにした。設定の「ドキュメントを開いたら入力モード」は、すべてのファイルに広げて「ファイルを開いたら操作モード」にした(ブラウザに覚えた値は名前が変わるので既定のオンに戻る)。

追記(2026-10-24): 複数選択はウィンドウ操作モードを経ずに、ノーマルモードの Space でできるようにした(選んで `i` で入るまでを短くするため)。操作モードのウィンドウが使わない Space は、キャンバスの選択には回さない(Markdown・CSV を読みながら押して選択が変わらないように)。キャンバスの `H`(Home の初期位置へ)は、Markdown の操作モードの `H`(戻る)と同じキーで、ノーマルモードと操作モードを取り違えると別の画面へ移ってしまうので外した。初期位置へは Tab で Home に戻ってから `H` で行く。また、Markdown と CSV の押しかけのキー(`gg` の1つ目の `g`)を、ウィンドウの部品の外で1つだけ持っていたため、複数のウィンドウで操作モードのとき、同じキーを配るたびに互いの途中の状態を上書きし、`gg` と `G` が片方にしか効かなかった。ウィンドウごとに持つように改めた。
