# 0025: ドキュメントウィンドウの操作の見直し(フェーズ6の確認を受けて)

- 日付: 2026-10-21
- フェーズ: 6
- 状態: 採用

ユーザーが確かめた結果を受けて、次のように変えた(spec 15.3・17.4 にも書いた)。(1) b.md の「上のディレクトリ」で Home へ移ったとき、Home のキーが効かず、一度 `Esc` を押すまで動かなかった。文書が入力モードのまま、表に出ていないキャンバスでキーを受け取って横取りしていたため。入力モードはキャンバスが表に出ている間だけ効くようにし、キャンバスへ戻ると入力モードに戻る。ライブウィンドウの入力モードにも同じ問題があった(履歴や Home を開いている間もキーをアプリへ送っていた)ので、同じく直した。(2) 文書の入力モードは `q` でも抜けられ、リンクヒントは `Backspace` でも閉じられるようにした。`q` は、開いているものがあってもすぐに抜ける(`Esc` は開いているものを先に閉じる)。ライブウィンドウではアプリが `q` を使うので対象外。(3) `f` で画像へのリンクを選んだときは、新しいウィンドウではなく、そのドキュメントウィンドウの中に画像を出し、ウィンドウ内の履歴に積む。`H` ですぐ文書へ戻れる気軽なプレビューとして使うため。新しいウィンドウで開きたいときは `F`(マウスでは Shift を押しながらクリック)。動画などほかの種類は今までどおり新しいウィンドウで開く。(4) コードブロックの右上にコピーボタンを置き、`f` のヒントでも選べるようにした。どのヒント(f / F / yf)で選んでもコピーする。Home のプレビューではボタンを出さない(操作できない表示のため)。
