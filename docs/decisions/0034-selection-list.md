# 0034: 選択中のファイルの一覧と、比較できるものの数え方

- 日付: 2026-11-03
- 状態: 採用

複数選択は別のディレクトリへ移っても残るのに、バーには件数しか出ず、どれを選んだか分からなくなることがあった(利用者の要望)。そこで、Home の「N 件を選択中」をボタンにし、押すか `m` で、選んだものの一覧を小さなウィンドウに出す。キーは、Home で空いていて、Space での選択をコード上 mark と呼んでいることと vim の `:marks` に合わせて `m` にした。一覧は閲覧範囲の起点からの相対パスで、別のディレクトリのものがまとまるようパスの順に並べる。各行のパスを押す(`l`・Enter)とそのディレクトリへ移ってそのファイルにカーソルを置き、「選択解除」(Space)で選択から外す。移動は j / k と gg / G で、履歴ウィンドウと同じ。ウィンドウはバーの右下に出し、後ろを暗くしない(開いている間に切り替えるヒントの帯が見えるように)。一覧の中のボタンを押したあとも Space・Enter が一覧のキーとして効くよう、ボタンにはフォーカスを移さず、キーはページ全体で先に受け取る。あわせて、「比較」ボタンは読める画像・動画が2つ以上選ばれているときだけ出すようにした。以前は種類を問わず2つ以上で出していたため、Markdown を複数選んでも出て、押すと「2つ以上選んでください」と矛盾したメッセージになっていた。ほかの種類のものが混ざっているときは、除いて比べ、除いた件数を知らせる。
