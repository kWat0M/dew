# 0019: 外部のツールが足りなくても、そのツールを使わない機能は動かす

- 日付: 2026-10-18
- フェーズ: 配布
- 状態: 採用

何も入っていない環境で試したところ、dew 自体は起動したが、ffprobe がないと動画の情報(`/api/probe`)が 500 で失敗し、ブラウザは情報が取れないと再生を始めない作りだったため、MP4 や PNG のようにブラウザがそのまま扱えるものまで「開けません」になっていた。このツールの最初の目的は、サーバ上の動画を見ることなので、機能ごとに要るツールを分け、足りないツールを使う機能だけを止めるようにした(ユーザーの指定)。ファイルの閲覧と、ブラウザがそのまま再生できる形式の再生にはツールが要らない。動画の情報・フレーム番号・コマ送りには ffprobe が要り、ないときはサーバが `Probe.missing` に "ffprobe" を入れた最小の結果を返して、ブラウザはそのまま再生を試み、長さと大きさは再生する側から取り、情報の欄(Home のプレビュー、プレイヤーのフレーム番号の場所)に足りないツールと入れ方を出す。サムネイル・シークバーのプレビュー・変換・TIFF と 16bit の画像には ffmpeg が要り、ないときは 503 と「〇〇には ffmpeg が要ります(導入: …)」を返して、その場所で知らせる(画像のプレビューは元の画像を出す)。ffprobe がないと変換が要るかを判断できないので、ブラウザで再生してみて、映像の大きさが取れない(音だけ再生できる mp4v など)か失敗したら、変換には ffmpeg が要ることを出す。ライブ描画(`dew run` / `dew env`)は Xvfb と ffmpeg がないと始められないので、そのときは足りないものと入れ方を出して止まる。pulseaudio がないときは止めずに、音なしで映して、そのことを知らせる。録画は ffmpeg で MP4 にするので、始めようとしたときに ffmpeg がなければ断って入れ方を出す。`dew` の起動時は、使えない機能を並べて知らせ、閲覧と再生はできることを伝える。`dew doctor` は、機能ごとに要るツールと、足りないとどうなるかを出す。
