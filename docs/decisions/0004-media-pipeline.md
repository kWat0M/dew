# 0004: サムネイル・スプライト・変換セグメントの作り方

- 日付: 2026-10-15
- フェーズ: 1
- 状態: 採用

画像のサムネイルも image クレートではなく ffmpeg で作る。ffmpeg は必須の依存で、動画と同じ1つの経路で WebP を出せ、TIFF や 16bit PNG も読めるため、依存を増やさずに済む。動画のサムネイルは長さの 10% の位置の画面にする(先頭は黒画面やタイトルが多いため)。シークバーのスプライトはキーフレームだけを復号して作り(`-skip_frame nokey`)、長い動画でも速く作れるようにする。そのため各画像の位置は最寄りのキーフレームにずれる。変換セグメントは fragmented MP4 で `-output_ts_offset` が効かなかったため、各セグメントを 0 秒始まりで作り、ブラウザが SourceBuffer の `timestampOffset` を「番号 × 6 秒」にして並べる(HLS と同じ考え方)。先頭の表示時刻がずれないよう B フレームを使わず(`-bf 0`)、AAC の先頭の無音で映像がずらされないよう `-avoid_negative_ts make_non_negative` を付ける。B フレームをやめると同じ画質で少しサイズが増えるが、変換結果は手元で見るための一時的なものなので許容する。
