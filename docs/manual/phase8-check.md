# フェーズ8の確認(2026-10-24、人が見る・操作する部分)

ビルドと、`dew` にパスを通す方法は `docs/manual/dev-build.md`。ビルドし直したら `dew stop` してから開く。

自動テスト(`tests/e2e/specs/phase8.spec.ts`)では、spec 11章「フェーズ8」の受け入れ基準を確かめている。ここでは見た目と操作感を見る。

1. **テーマ**: 操作パネル(右上の `⋮`)の「テーマ」で「ライト」「ダーク」を押す。全体と枠の色が変わり、読み直しても(F5)一瞬も別の色にならないか。「ブラウザに合わせる」に戻し、Windows の設定のライト / ダークに従うか。セグメントボタンの見た目(選んだものにチェック)が MD3 らしいか
2. **保存(ファイル)**: Home で日本語の名前のファイルを選んで `D`。ブラウザの保存に同じ名前で出るか。キャンバスでタイトルバーの保存のボタン(下向きの矢印)と、ノーマルモードの `D` でも同じか
3. **保存(zip)**: Home でディレクトリを選んで `D` → `<名前>.zip`。`Space` で複数を選んで `D`(上のバーの「保存」ボタンでも)→ `dew-<日時>.zip`。展開して中身とディレクトリの形が元どおりか。大きなディレクトリ(1 GB 超)では確認の画面が出て、保存がすぐに始まるか
4. **スマホ**: スマホから ssh でサーバに入り、`dew url` の URL をタップして開く(PC なら、ブラウザの開発者ツールで幅 390px のスマホ表示にしても見られる)
   - Home: 1カラムで、行をタップするとディレクトリの中へ、ファイルはキャンバスで開く。左上の矢印で親へ戻る。パンくずは今のディレクトリが見えるように右端まで送られているか。右下のボタンでキャンバスへ
   - キャンバス: ウィンドウが1つずつ全画面で出て、上のタブで切り替わる。Markdown を指でスクロールでき、リンクをタップすると移る。下部のバーのボタンが押しやすいか(2段に折り返す)
   - CSV: 指でスクロールでき、下部のボタンからフィルターなどを使えるか
   - 操作パネル・履歴: 画面いっぱいに出て、履歴はタップで開くか
   - 押しにくい部品、はみ出して見えない部品がないか
