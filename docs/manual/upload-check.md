# アップロードの確認(2026-11-13、人が見る・操作する部分)

ビルドと、`dew` にパスを通す方法は `docs/manual/dev-build.md`。ビルドし直したら `dew stop` してから開く。

自動テスト(`tests/e2e/specs/upload.spec.ts`)では、spec 11章「アップロード」の受け入れ基準を確かめている。ドラッグ&ドロップは自動テストではページの中で作ったファイルで試しているので、ここでは Windows のエクスプローラーからの操作と見た目を見る。

1. **ボタン**: Home で書き込めるディレクトリへ移り、上部のバーの上向きの矢印(保存のボタンの右)を押す。Windows のファイルの選択画面が開き、複数を選んで「開く」で送られるか。終わると「N 件をアップロードしました」と出て、送ったファイルにカーソルが合うか
2. **キー**: `U` でも同じ選択画面が開くか
3. **ドラッグ&ドロップ**: エクスプローラーからファイルを Home の画面へドラッグする。2カラム目に点線の枠と「ここに置くと <ディレクトリ> にアップロードします」が出るか。画面の外へ出すと消えるか。置くと送られるか。フォルダを混ぜて置くと「ディレクトリ N 件は送りません」と出て、ファイルだけ送られるか
4. **大きなファイル**: 数百 MB〜数 GB のファイルを送り、上部のバーの「アップロード中 1 / 1(N%)」が進むか。途中でそれを押すと中止し、ディレクトリに書きかけ(`.dew-upload-…`。隠しファイルを表示して確かめる)が残らないか
5. **同じ名前**: 同じファイルをもう一度送ると「名前 (1).拡張子」で保存され、そのことが出るか
6. **キャンバス**: キャンバスへファイルを置くと「アップロードは Home で行います」と出て、ブラウザがそのファイルを開かないか
7. **スマホ**: スマホで Home を開き、アップロードのボタンから写真などを選んで送れるか(ボタンが押しやすいか)
8. **書き込めない場所**: 書き込み権限のないディレクトリで送ると「書き込み権限がありません」と出るか
