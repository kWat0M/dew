# フェーズ4(精度・記録)を人が確かめる手順

受け入れ基準は E2E と単体テストで確かめている。ここでは、見た目・操作感と、GPU のある環境での NVENC を確かめる。WSL の開発用コンテナ(または手順書 remote-test.md のテスト用コンテナ)と、Windows のブラウザ(Zen / Chrome)で行う。

## 準備(開発用コンテナで)

```bash
cd ~/projects/DevView
pnpm -C web build && cargo build -p dew
alias dew=$PWD/target/debug/dew
dew            # 出た URL を Windows のブラウザで開き、「クリックかキーで開始」を押す
```

## 確かめること

| # | 操作 | 期待する見た目・操作感 |
|---|---|---|
| 1 | `dew run --exact python3 tests/apps/exact_sample.py &` | 「exact」のウィンドウに砂嵐のような画像が出て、下のバーに「精度モード」と出る。`z`(等倍)で見ると、にじみやブロックのない、くっきりした点の集まりに見える |
| 2 | 1 のウィンドウで `i` を押してから `Esc` | アプリが終わり、ウィンドウに「終了」と出る(waitKey に Esc が届いた) |
| 3 | `dew run python3 tests/apps/counter.py &` を開き、`R` で録画を始め、数秒後にもう一度 `R` | 「録画中」の印が出て消え、「録画を保存しました: dew-recordings/counter-….mp4」と出る。Home の `dew-recordings/` からその MP4 を開くと再生できる |
| 4 | 3 のウィンドウで、下のバーの一時停止ボタン(または `k`) | 映像が止まり、バッファのバーと「何秒前」「ライブへ戻る」が出る。`j` / `l` で5秒ずつ、バーのドラッグで好きな位置へ動ける |
| 5 | 4 の状態で `k` | 巻き戻した位置から再生が進む。「ライブへ戻る」で今の映像に戻る |
| 6 | 30 秒以上流したあとに一時停止して `0` | 約30秒前の映像が出る |
| 7 | `dew doctor` | 「ライブ映像のエンコード」の行に、NVENC を使うか libx264 を使うかが出る。GPU のあるサーバでは NVENC になる |

GPU のあるサーバでは、7 で NVENC と出たうえで 3〜5 を試し、映像が乱れないかも見る。気になった点は、手順の番号と一緒に伝える。終わったら `dew stop`。
