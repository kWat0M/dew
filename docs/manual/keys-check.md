# キー操作の見直しの確認(2026-10-24、人が見る・操作する部分)

ビルドと、`dew` にパスを通す方法は `docs/manual/dev-build.md`。ビルドし直したら `dew stop` してから開く。

自動テスト(`tests/e2e/specs/keys.spec.ts`)では、spec 11章「キー操作の見直し」の受け入れ基準を確かめている。ここでは見た目と操作感を見る。素材は `scripts/gen-fixtures.sh` で `tests/fixtures/` にできる。

1. **枠の色**: 動画を2つ開く(Home で `Space` で2つ選んで Enter)。開いた直後のウィンドウは緑の太めの枠(操作モード)。`Esc` で青の枠(フォーカスだけ)。ライト / ダーク(Windows の設定)の両方で、青・緑・紫が見分けやすく、明るすぎないか
2. **ノーマルモード**: `h` `j` `k` `l` と矢印でウィンドウを選べる。`h` で Home へ戻らない(`Tab` で戻る)。ヒントの帯が「ウィンドウを選ぶ」「操作モード」などに変わる
3. **操作モード**: `i` か `Enter` で入り、`k` で再生、`j` / `l` で 5 秒。`Esc`・`q`・`Ctrl+[` で抜ける。ヒントの帯が動画のキーに変わり、最後に「操作モードを抜ける」が出る
4. **マウス**: 止まっている動画の本体を1回押すと操作モード(再生しない)、もう1回で再生 / 停止。別のウィンドウを押すとそちらへ。タイトルバーはフォーカスだけ(緑にならない)。ヒントの帯・タブバー・何もない所を押すと抜ける。操作パネルを押しても抜けない
5. **まとめて操作**: `Esc` の後、`Space` → `h` → `Space` で2つ選び(タイトルバーにチェック)、`i`。両方が緑になり、`k` で両方が再生する。`tests/fixtures/md` の Markdown 2つでも同じにし、`j` で両方スクロール、`G` と `gg` で両方が末尾・先頭へ、`f` で両方にヒント(文字が重ならない)
6. **CSV**: `cd tests/fixtures/csv && dew rows10k.csv`。`f` でフィルター → 値の欄に入っていてすぐ打てる。`Esc` で欄から抜け(画面は残る)、`k` で条件の欄へ、`Enter` で一覧(MD3 の Menu)を開いて `j` / `k` で選び `Enter`。`M`(強調)でも、矢印で欄を移り `Enter` で入れるか。選んでいる欄の印(枠)が見やすいか
7. **検索欄**: CSV と Markdown の `/` で打ってから `Esc` → 欄は残り、表 / 文書のキーが効く。`/` で欄に戻り、`Esc` 2回で閉じる。Home の `/` も同じ(1回目の `Esc` で絞り込みは残り、もう一度 `Esc` で解除)
8. **ライブ**: `dew run python3 tests/apps/counter.py`。出てきたときは緑(操作モード)。`i` で紫(入力モード)、`Esc` がアプリに届き、`Ctrl+[` で緑に戻る。`k` で一時停止(巻き戻し)、`G` でライブへ戻る。2つ起動して選んでから入ると、打った文字が両方に届く
9. **Home のプレビュー**: ディレクトリを選ぶと右に中身が出る。その中のディレクトリを押すとその中へ(押したものが左のカラムで選ばれる)、ファイルを押すとキャンバスで開く。ブラウザの戻るで戻れる
10. **日本語配列**: `Ctrl+[` が、刻印どおりの `[` で効くか(以前は物理キーの位置で `Ctrl+]` と見なしていた)
