# フェーズ6の確認(人が見る・操作する部分)

ビルドと、`dew` にパスを通す方法は `docs/manual/dev-build.md`。

自動テストでは、要素が描画されること、危険な内容が動かないこと、キー操作で移動することを確かめている。ここでは見た目と操作感を見る。素材は `scripts/gen-fixtures.sh` で `tests/fixtures/md/` にできる。

```bash
cd tests/fixtures && dew md/all.md
```

1. **見た目**: 見出し・表・タスクリスト・打ち消し線・数式(誤った式だけ赤い字)・色分けしたコード・上部の「メタデータ」(開くとフロントマター)。ライト / ダーク(Windows の設定)の両方で、文字と背景の色が読みやすいか
2. **操作感**: `j` / `k`、`d` / `u`、`gg` / `G`、`+` / `-` / `=`(5段階)。`f` でリンクに文字が付き、打つと開く(`Backspace` で閉じる。`Esc` では閉じない。ヒント中は画面下の帯に抜け方が出る)。`F` は新しいウィンドウで、`yf` はリンクのパスのコピー。コードブロックの右上のボタン(`f` でも選べる)でコードをコピー
3. **移動**: `dew md/a.md` → `d` を何回か押して「B へ移動」を `f` で開く → `H` で元の位置へ、`L` で進む。「画像を見る」を `f` で選ぶと同じウィンドウに画像が出て、`H` で戻る(`F` なら新しいウィンドウ)。b.md の「上のディレクトリ」は Home で開き、すぐに Home のキーが効く
4. **目次と検索**: `o` で目次、`j` / `k` で選んで Enter。`/` で検索し、Enter のあと `n` / `N`
5. **更新**: エディタで開いている Markdown を保存すると、位置を保ったまま描き直る。ファイルを消すと「削除されました」と出て、最後の内容が残る
6. **文字コード**: `dew md/sjis.md` → 下部に Shift_JIS。押して UTF-8 にすると化け、Shift_JIS に戻すと直る。入力モードの `e` でも順に切り替わり、Snackbar に出る
7. **入力モード**: 開いた直後から `j` が効く。`Esc` では抜けず、`q` か `Ctrl+]` で抜けたあとに `j` を押すと「i で操作できます」が1回出る。`w` や Tab が効く
8. **画像**: `dew md/images.md` → 相対の画像は出る。範囲外は「閲覧範囲外」、外部は「クリックで読み込む」。操作パネルの設定で、外部の画像を常に読み込むにもできる
9. **Home のプレビュー**: Home で Markdown を選ぶと、右のカラムに先頭が小さく描かれる
10. **マウス**: 下部のバーの 戻る・進む、検索・目次・文字の大きさのボタン(説明にキーが出る)。リンクの中クリックで新しいウィンドウに開き、ブラウザのタブは増えない。**マウスのサイドボタン**で戻る・進むができ、ブラウザ自体のページは移らない(自動テストではサイドボタンを押せないので、Chrome と Firefox の両方で確かめる)
