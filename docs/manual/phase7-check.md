# フェーズ7の確認(人が見る・操作する部分)

ビルドと、`dew` にパスを通す方法は `docs/manual/dev-build.md`。ビルドし直したら `dew stop` してから開く。

自動テストでは、受け入れ基準(spec 11章)の12項目と、両モードの結果の一致、マウスだけの操作を確かめている。ここでは見た目と操作感を見る。素材は `scripts/gen-fixtures.sh` で `tests/fixtures/csv/` にできる。

```bash
cd tests/fixtures/csv && dew rows10k.csv
```

1. **見た目**: ヘッダーと行番号は、縦・横にスクロールしても見えたまま。数値は右寄せ、空のセルは薄い「—」。選んだセルは primary の枠。ライト / ダーク(Windows の設定)の両方で読みやすいか
2. **移動**: `hjkl`、`J` / `K`(1画面)、`d` / `u`(半画面)、`H` / `L`(1画面分 左右)、`gg` / `G`、`0` / `$`、`:` に続けて行番号と Enter。画面の外へ出ると自動でスクロールする
3. **並べ替え・フィルター・検索**: `s`(昇順 → 降順 → 解除)、`S` で第2キー。`f` でフィルター(条件と値、Enter)、`F` で全部解除。`/` で検索し `n` / `N`。下部に行数(フィルター後 / 全体)・選択中のセル(`C7` など)・並べ替えの状態が出る
4. **表示だけの変更**: `+` / `-`(小数の桁)、`r`(表示名。見出しにマウスを載せると元の列名)、`m`(マーク)、`M`(条件付き強調。色を4つまで)、`x` / `X`(隠す / 全部出す)、`p`(左に固定)、`<` / `>` / `=`(列幅)、`o`(文字コード・区切り文字・ヘッダー・桁区切り)、`R`(全部初期化)。`y` / `Y` でコピーしたものが元の値か
5. **マウス**: 列の見出しにマウスを載せるとメニューのボタンが出る。並べ替え・フィルター・表示名・隠す・固定・列幅・小数の桁ができる。セルのクリックで選び、ダブルクリックで全文。操作パネルの一番下の CSV の節からも全操作ができる。フィルターなどの小さな画面は、操作パネルを開いていても隠れない
6. **設定が残る**: 並べ替えや表示名を変えてからタブを読み直し(F5)、もう一度 `dew rows10k.csv` すると戻る。`dew stop` のあとは初期状態
7. **大きなファイル**: `dew rows1m.csv`(約 100 MB)。読み込み中は進捗のバーが出る(配布用ビルドで約 2 秒、開発ビルドで約 8 秒)。下部に「大規模」。並べ替え・フィルターがすぐ(0.1 秒ほどで)変わるか。もう一度開く(`dew stop` のあとも)と、読み込みを待たずに出るか
8. **文字コード**: `dew sjis.csv` → 下部に Shift_JIS。`o` で UTF-8 に変えると化け、戻すと直る
9. **不揃い・広い表**: `dew ragged.csv` → 下部に「列数が不揃いな行: 3 行」(赤)。`dew wide.csv` → 1,000 列でも横スクロールが重くないか
10. **更新**: エディタで開いている CSV に行を足して保存すると、1秒以内に表に出て、選んでいたセルは同じ所にある
11. **Home のプレビュー**: Home で CSV を選ぶと、右のカラムに先頭20行・10列までの小さな表と、文字コード・区切り文字が出る
